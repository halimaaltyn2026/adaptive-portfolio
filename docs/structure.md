# Этап 1. Подготовка портфолио

## 1. Описание читателя сайта
Сайт открывает потенциальный заказчик с биржи фриланса (владелец малого бизнеса) или HR-специалист. За одну минуту он хочет увидеть мои навыки и живые примеры работ. Ему важно быстро понять уровень верстки и сразу найти контакты в Telegram для связи.

## 2. Structure сайта
Сайт состоит из четырех основных страниц:
1. **Главная страница** — приветствие и ключевые навыки.
2. **Список работ** — каталог моих проектов.
3. **Страница кейса** — подробный разбор конкретной работы.
4. **Контакты** — ссылки на мессенджеры для связи.
